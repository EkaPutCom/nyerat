Cara kerja

Dari “ada yang tidak sinkron?” sampai selesai.

Folder kerja berisi rencana peluncuran, catatan rapat, riset, dan papan tugas. Cukup minta dengan bahasa biasa:

  • “Adakah keputusan rapat yang belum masuk ke rencana peluncuran?” Agent menemukan rilis yang diundur ke 22 November, sementara rencana masih 15 November
  • “Perbarui tanggal rilisnya dan pindahkan kartu materi rilis ke Dikerjakan.” Dua usulan muncul untuk ditinjau, masing-masing dengan selisihnya
  • Untuk pekerjaan beberapa langkah, agent memeriksa hasilnya, misalnya tanggal lama tidak tersisa di berkas mana pun, sebelum menyatakan selesai

Kendali ada di Anda

Setiap tindakan bisa diperiksa dulu.

  • Alat baca langsung berjalan; alat tulis hanya menghasilkan usulan
  • Hanya berkas Markdown di folder kerja; nama di luar folder, bertitik, atau berisi .. ditolak
  • Berkas yang berubah sejak diusulkan tidak ditimpa; agent diminta mengusulkan ulang
  • Hapus berarti ke Tempat Sampah, dan setiap penerapan bisa diurungkan
  • Saklar konteks menentukan dokumen yang dikirim ke DeepSeek, dengan API key milik Anda
  • Semua tetap Markdown biasa yang bisa di-diff dan di-commit ke Git

Belum tersedia: pemeriksaan kontradiksi otomatis, penyedia model selain DeepSeek, dan agent Nyerat yang menjalankan perintah. Lihat keterbatasan.

Sampai terverifikasi

Belum lulus pemeriksaan, belum selesai.

Untuk pekerjaan beberapa langkah, agent menyusun rencana yang terlihat di panel, mengusulkan perubahannya sebagai satu paket, lalu membaca ulang hasil sungguhan.

  • Rencana dengan langkah yang dicentang saat ada kemajuan
  • Pemeriksaan teks wajib ada atau hilang di seluruh folder, posisi kartu, dan struktur Markdown
  • Paket bisa diurungkan, dan pekerjaan yang terputus bisa dilanjutkan

Orkestrator

Tugaskan kartu ke agent lain.

Tulis @pi di kartu kanban, klik kanan, lalu Kerjakan dengan pi. Harness pi bekerja di repo proyek yang Anda pilih, dan Nyerat mengatur sisanya.

  • Kartu pindah ke Dikerjakan saat mulai dan ke Review saat selesai, dengan ringkasan hasil
  • Pertanyaan dan permintaan izin pi dijawab dari kartu: Jawab pi…, Beri Arahan, atau Balas
  • Satu proyek dikerjakan satu harness; kartu lain mengantre
  • Log pi berisi alat, penalaran, token, biaya, dan id sesi
