Editor Markdown yang
AI-native.

Asisten AI di Nyerat sudah membaca seluruh naskah Anda: dokumen yang terbuka, pilihan, dan semua berkas di folder. Tanya apa saja tanpa salin-tempel, dan jawabannya datang dengan kutipan berkas dan nomor baris. Menulisnya tetap bersih, tanpa pratinjau terpisah.

Fitur

AI yang paham naskah, editor yang tidak mengganggu

Semua yang dibutuhkan untuk menulis catatan, dokumentasi, dan rencana kerja, dalam satu jendela GTK yang ringan.

✦

AI di inti editor (DeepSeek)

Tanya soal naskah Anda di panel samping. Asisten sudah membaca naskah: ia menyusun konteks otomatis dan menelusuri berkas di folder untuk menemukan, misalnya, kontradiksi antarbab. Hanya membaca, tidak pernah mengubah berkas.

❏

Riwayat percakapan per folder

Percakapan dengan asisten disimpan sebagai berkas Markdown di .nyerat/chats dalam folder naskah. Buka lagi dan lanjutkan kapan saja; folder itu tidak ikut Git secara otomatis.

✎

Penulisan langsung terformat

Heading, tebal, miring, coret, stabilo, kode inline, tautan, dan gambar langsung terformat. Sintaksnya muncul lagi saat kursor ada di baris itu.

▦

Papan kanban

File Markdown dengan kanban: true dibuka sebagai papan ala Trello. Setiap perubahan ditulis kembali sebagai teks Markdown biasa.

⊞

Tabel sebagai grid

Tabel digambar dengan garis sel dan rata kolom. Tab pindah antar sel, dan menu Edit Tabel menambah atau menghapus baris dan kolom.

◇

Diagram Mermaid dan DBML

Flowchart, sequence, class, ER, gantt, dan skema dbdiagram.io dirender langsung di dokumen, ikut berubah selagi Anda mengetik.

{ }

Blok kode berwarna

Ratusan bahasa diwarnai lewat GtkSourceView, dengan skema warna yang mengikuti mode terang atau gelap.

◐

Mode gelap

Otomatis mengikuti tema sistem saat pertama dibuka, dan bisa diganti kapan saja dari menu.

⧉

Banyak dokumen, satu jendela

Buka beberapa file sebagai tab. Tiap tab punya undo, kursor, dan posisi gulir sendiri, dan asisten ikut membaca tab yang belum disimpan.

▤

Sidebar berkas dan outline

Buka sebuah folder dan telusuri file Markdown-nya, atau lompat antar heading lewat outline dokumen.

⎘

Kelola berkas di pohon

Klik kanan untuk membuat file atau folder baru, mengganti nama, dan menghapus (ke Tempat Sampah). Seret dan lepas untuk memindahkan.

⑂

Riwayat Git

Lihat commit untuk file yang dibuka, baca diff dan isi tiap versi, lalu commit satu atau beberapa file yang berubah langsung dari sidebar.

⌕

Zoom gambar

Gambar lokal maupun dari internet tampil di bawah barisnya. Klik ganda untuk membuka penampil dengan zoom, geser, dan pas layar.

↻

Auto save

Dokumen yang sudah punya file disimpan otomatis sesaat setelah Anda berhenti mengetik, dengan peringatan jika ada yang belum tersimpan.

◎

Mode fokus dan typewriter

Redupkan semua paragraf selain yang sedang disunting, atau jaga baris aktif tetap di tengah layar.

⇪

Ekspor HTML

Simpan dokumen sebagai satu file HTML mandiri, CSS-nya sudah disertakan. Ctrl+Shift+E.

Tulis

Ketik Markdown, langsung jadi.

Tidak ada panel di sebelah kanan dan tidak perlu menekan tombol pratinjau. Tulisan Anda sudah berbentuk akhirnya sejak huruf pertama.

  • Enter melanjutkan daftar, daftar bernomor, dan kutipan
  • Daftar tugas bisa dicentang dengan klik
  • Tab dan Shift+Tab mengatur indentasi daftar

Fokus ke isi

Sintaks muncul hanya saat dibutuhkan.

Pindahkan kursor ke baris mana pun, dan tanda **, ==, atau []() muncul untuk disunting. Pindah lagi, dan baris itu kembali bersih.

Diagram

Diagram yang ikut berubah selagi Anda mengetik.

Blok ```mermaid dan ```dbml digambar sebagai diagram. Masuk ke blok untuk menyunting kodenya, dan pratinjau di bawahnya diperbarui seketika.

  • Flowchart, sequence, class, state, ER, gantt, pie, dan lainnya
  • DBML (dbdiagram.io) digambar sebagai diagram ER
  • Dirender lokal, tidak perlu internet
  • Galat sintaks muncul di bawah blok, lengkap dengan nomor barisnya

Kanban

Papan kerja yang tetap berupa teks.

Heading ## menjadi daftar dan item - [ ] menjadi kartu. Papan disimpan sebagai file Markdown biasa yang bisa dibaca, di-diff, dan di-commit ke Git.

  • Seret kartu antar daftar, atau pindahkan lewat menu klik kanan
  • #tag menjadi label berwarna, @{2026-10-20} menjadi tanggal tenggat
  • Undo dan redo tetap berfungsi untuk perubahan di papan

Asisten

Tanya naskah Anda, jawabannya berikut kutipan.

Panel Asisten (Ctrl+Shift+A) menyusun konteks dari dokumen, pilihan, dan berkas lain di folder, lalu menelusuri naskah sendiri dengan alat baca-saja sebelum menjawab.

  • Jawaban mengalir dan menyebut berkas serta nomor barisnya
  • Tiap jawaban memperlihatkan konteks dan pemakaian token
  • Hanya membaca: tidak pernah mengubah berkas Anda
  • Percakapan tersimpan per folder sebagai Markdown, bisa dilanjutkan lagi
  • Naskah yang disertakan dikirim ke DeepSeek; saklar konteks bisa dimatikan

Riwayat Git

Lihat dan simpan versi tulisan, tanpa keluar editor.

Tab Riwayat menampilkan commit untuk file yang dibuka. Klik satu commit untuk membaca diff dan isi versinya.

  • Daftar file yang belum di-commit, dengan kotak centang
  • Commit beberapa file sekaligus dari sidebar
  • Diff berwarna dan isi lengkap tiap versi

Pasang

Jalan dalam tiga langkah

Nyerat dijalankan oleh GJS, bukan Node.js. Node.js hanya dibutuhkan untuk membangun kodenya sekali.

Pasang kebutuhan sistem

Di Ubuntu atau Debian. WebKitGTK hanya dipakai untuk diagram Mermaid dan DBML, dan libsoup untuk asisten; tanpanya aplikasi tetap berjalan.

# GJS, GTK 3, dan GtkSourceView
sudo apt install gjs gir1.2-gtk-3.0 gir1.2-gtksource-4

# opsional: untuk diagram
sudo apt install gir1.2-webkit2-4.1

# opsional: untuk asisten AI (butuh API key DeepSeek)
sudo apt install gir1.2-soup-3.0 gir1.2-secret-1

Ambil kodenya

Perlu Node.js 20.19+ atau 22.12+ untuk build.

git clone https://github.com/EkaPutCom/nyerat.git
cd nyerat
npm install

Build dan jalankan

npm start

# atau buka file/folder tertentu setelah di-build
gjs -m dist/nyerat.js catatan.md
gjs -m dist/nyerat.js ~/catatan
