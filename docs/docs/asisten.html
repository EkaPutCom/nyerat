Agent

Panel Asisten

Tempat Anda bekerja dengan agent: bertanya, meminta rencana, atau meminta perubahan dengan bahasa biasa.

Membuka panel

Tekan Ctrl+Shift+A atau tombol gelembung di header bar. Panel muncul di sisi kanan dan ikut diingat saat aplikasi dibuka lagi. Enter mengirim pesan, Shift+Enter membuat baris baru.

Kepala panel berisi tombol:

  • Jam: daftar percakapan tersimpan di folder ini (Riwayat percakapan)
  • Sapu: percakapan baru
  • Terminal: jendela Log agent (Log agent)
  • Roda gigi: API key, model, mode berpikir, dan saklar simpan riwayat

Model dan mode berpikir

Agent memakai model DeepSeek: deepseek-flash (bawaan) atau deepseek-v4-pro, dipilih di pengaturan panel. Kotak Berpikir mendalam menyalakan mode berpikir yang lebih teliti tetapi lebih lambat dan mahal. Proses berpikir model bisa dibuka terpisah di atas jawaban dan tidak disimpan ke berkas percakapan.

Jawaban

  • Jawaban mengalir saat dibuat dan tampil dengan format Markdown.
  • Kutipan menyebut berkas dan nomor baris, mis. rapat-1-okt.md:12.
  • Tiap penelusuran tampil sebagai baris kecil di atas jawaban, mis. Mencari teks “Raka” → 3 baris.
  • Di bawah jawaban ada rincian konteks yang dikirim dan pemakaian token, termasuk bagian yang dilayani dari cache.
  • Tombol Hentikan membatalkan jawaban yang sedang berjalan; hasilnya dikirim balik ke model supaya tidak memaksa.

Meminta tindakan

Bila Anda meminta perubahan, agent memanggil alat usulan. Jendela tinjau terbuka otomatis, dan di panel tertinggal kartu ringkas berstatus dengan tombol Tinjau perubahan. Lihat Usulan dan persetujuan.

Contoh permintaan yang cocok:

  • “Buat ringkasan riset pesaing di folder riset.”
  • “Ganti semua ‘Raka’ menjadi ‘Rakai’ di catatan rapat.”
  • “Tambahkan kartu ‘Siapkan demo’ ke daftar Rencana dengan tag #rilis.”
  • “Kapan tanggal rilis diubah dan oleh siapa?” (dijawab dari riwayat Git)

Keandalan koneksi

Kegagalan koneksi, HTTP 429, dan galat 5xx dicoba ulang paling banyak dua kali, hanya bila belum ada teks yang tampil. Galat autentikasi tidak diulang. Aliran yang terputus sebelum selesai dianggap gagal, dan panggilan alat yang belum lengkap tidak dijalankan.
