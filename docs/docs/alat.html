Daftar alat agent

Semua alat yang bisa dipanggil agent Nyerat. Alat baca langsung dijalankan; alat usulan selalu menunggu persetujuan Anda di jendela tinjau.

AlatFungsiPersetujuan

cari_teksCari teks persisTidak
baca_berkasBaca isi berkas per rentang barisTidak

Syarat ketersediaan

  • Alat baca dan usulan hanya ditawarkan bila saklar Berkas lain di folder menyala dan sebuah folder kerja dibuka.
  • Satu pertanyaan menjalankan paling banyak 10 putaran model; putaran terakhir tanpa alat.
