Agent

Menelusuri berkas dan Git

Konteks awal hanya bagian yang dipilih otomatis. Untuk sisanya, agent menelusuri ruang kerja sendiri dengan alat baca-saja yang langsung dijalankan tanpa persetujuan.

Alat baca berkas

AlatFungsi
daftar_berkasDaftar berkas Markdown di folder kerja beserta jumlah kata dan heading-nya
cari_dokumenCari bagian berkas menurut topik (BM25)
cari_teksCari teks persis, mis. nama, tanggal, atau angka
baca_berkasBaca isi berkas per rentang baris, bernomor

Untuk pertanyaan seperti “adakah keputusan rapat yang belum masuk ke rencana peluncuran?”, agent mencari semua kemunculan topiknya, membaca bagian sekitarnya, lalu menjawab dengan kutipan berkas dan nomor baris.

  • Dokumen yang terbuka dibaca dari isi editor, bukan dari disk.
  • Hanya berkas Markdown di folder kerja yang dibaca.
  • Tiap hasil dibatasi 6.000 token, dan total hasil baca sebesar anggaran konteks.
  • Alat hanya ada bila saklar Berkas lain di folder menyala.

Alat riwayat Git

Bila folder kerja adalah repositori Git, agent juga bisa membaca riwayatnya:

AlatFungsi
riwayat_gitCommit terbaru untuk seluruh folder atau satu berkas (mengikuti ganti nama), beserta berkas yang berubah
lihat_commitDiff satu commit
isi_versiIsi berkas pada commit lama, termasuk berkas yang sudah dihapus

Pertanyaan seperti “kapan tanggal rilis diubah dan oleh siapa?” dijawab dari riwayat.

Batas akses Git

git dijalankan di folder kerja dengan pathspec yang hanya mencakup berkas Markdown tidak tersembunyi. Commit hanya boleh berupa hash atau HEAD~n. Tidak ada perintah git yang mengubah repositori.

Tips

  • Pencarian berbasis kata kunci, bukan makna. Sebut istilah yang benar-benar ada di naskah agar agent cepat menemukannya.
  • cari_teks tidak mengenali sinonim atau ejaan berbeda.
  • Pertanyaan yang luas memakan lebih banyak putaran dan token. Lampirkan berkas dengan @ bila Anda sudah tahu tempatnya.
