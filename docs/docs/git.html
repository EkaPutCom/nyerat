Ruang kerja

Riwayat Git

Lihat dan simpan versi tulisan tanpa keluar editor. Butuh git terpasang dan folder kerja di dalam repositori.

Daftar commit

  • Commit yang menyentuh berkas yang dibuka, terbaru dulu, mengikuti berkas yang di-rename.
  • Klik commit untuk membuka jendela dengan dua tab: Perubahan (diff berwarna) dan Isi versi ini.
  • Dimuat 100 commit sekali muat, dengan tombol Muat lebih banyak.

Perubahan belum di-commit

  • Tombol Perubahan belum di-commit membuka diff berkas yang dibuka terhadap HEAD.
  • Daftar Belum di-commit (N) memuat semua berkas yang berubah di repositori (M, A, D, R, U), masing-masing dengan kotak centang.
  • Isi pesan lalu tekan Commit N file untuk meng-commit beberapa berkas sekaligus. Dokumen yang terbuka disimpan dulu.

Riwayat untuk agent

Agent bisa membaca riwayat yang sama lewat riwayat_git, lihat_commit, dan isi_versi, tetapi tidak pernah mengubah repositori. Lihat Menelusuri berkas dan Git.
