Ruang kerja

Jurnal harian

Jurnal mencatat apa yang terjadi di pekerjaanmu hari ini. Kamu menulis catatan singkat kapan saja, dan Nyerat melengkapinya dengan aktivitas kerja yang sudah terjadi: kartu yang dipindah, perubahan agent yang kamu setujui, hasil harness, dan commit Git. Semuanya tersimpan sebagai berkas Markdown biasa.

Membuka jurnal hari ini

  • Ctrl+Alt+J, menu ☰ → Jurnal Hari Ini, atau baris Jurnal hari ini di Beranda.
  • Jurnal disimpan di jurnal/YYYY-MM-DD.md di folder kerja. Bila belum ada, berkasnya dibuat dari template berjudul tanggal hari ini dengan bagian Fokus hari ini, Catatan, Aktivitas, dan Ringkasan.
  • Jurnal butuh folder kerja yang terbuka (Ctrl+Shift+O).
  • Jurnal adalah dokumen biasa: sunting, simpan, commit, dan tautkan dengan [[catatan]] seperti berkas lain. Jurnal hari lain dibuka dari pohon berkas.

Catat cepat

Ctrl+Shift+J (atau tombol + di baris Jurnal di Beranda) membuka dialog satu baris. Teksnya masuk ke akhir bagian Catatan sebagai butir berstempel jam, misalnya - 11:40 Flatpak belum bisa diuji di mesin ini, tanpa meninggalkan dokumen yang sedang kamu kerjakan.

  • Bila jurnal hari ini sedang terbuka di tab, catatan masuk lewat editornya sebagai satu langkah undo. Bila tidak, catatan langsung ditulis ke berkasnya (berkas dibuat dari template bila belum ada).
  • Penanda bebas dipakai sesukamu, misalnya ! untuk hambatan, ? untuk pertanyaan, atau → untuk dilanjutkan besok. Nyerat tidak menafsirkannya, tetapi Asisten bisa memakainya saat meringkas.

Aktivitas otomatis

Sepanjang hari Nyerat mencatat aktivitas kerja di folder kerja ini:

  • Kartu kanban yang pindah daftar, dicentang selesai, atau baru ditambahkan, dari tampilan papan, dari centang di Beranda, atau dari harness. Kartu yang hanya disunting teksnya tidak dicatat.
  • Perubahan agent yang kamu terapkan dari jendela tinjau (juga saat diurungkan).
  • Hasil harness, misalnya pi selesai “Fix checkout” di proyek toko.
  • Commit Git hari itu di repo folder kerja (dibaca langsung dari git log saat jurnal dibuka).

Saat jurnal dibuka, aktivitas yang belum ada digabung ke bagian Aktivitas sebagai butir berstempel jam. Nama papan dan berkas ditulis sebagai tautan [[…]] yang bisa dibuka dengan Ctrl+klik. Penggabungan hanya menambah baris: baris yang kamu sunting atau hapus tidak ditimpa, dan satu kali Ctrl+Z membatalkan seluruh penggabungan.

Log aktivitasnya disimpan di .nyerat/aktivitas/YYYY-MM-DD.jsonl di folder kerja (diabaikan Git lewat .nyerat/.gitignore, dan tidak ditelusuri agent).

Ringkasan akhir hari

Palet perintah (Ctrl+Shift+P) → Ringkas Jurnal dengan Asisten membuka jurnal hari ini, membuka panel Asisten, dan memintanya mengusulkan ringkasan di bawah Ringkasan: apa yang selesai, apa yang menghambat, dan apa yang dilanjutkan besok. Usulan itu tampil di jendela tinjau seperti perubahan agent lainnya, jadi tidak ada yang tertulis sebelum kamu menekan Terapkan. Butuh API key DeepSeek.

Di Beranda

Beranda menampilkan baris Jurnal hari ini dengan jumlah catatan di jurnal dan aktivitas yang tercatat hari ini (termasuk yang belum digabung ke berkas). Klik barisnya untuk membuka jurnal, atau tombol + untuk catat cepat.
