Keterbatasan

Daftar jujur tentang yang belum tersedia, supaya Anda tahu batasnya sebelum mengandalkannya.

Agent

  • Penyedia model baru DeepSeek.
  • Belum ada pemeriksaan kontradiksi otomatis; kontradiksi bisa ditanyakan lewat chat.
  • Agent Nyerat hanya menyentuh berkas Markdown di folder kerja. Menjalankan perintah hanya dilakukan harness eksternal dari kartu kanban.
  • Paket maksimal 20 tindakan. Memindah berkas tidak memperbarui tautan di berkas lain; agent harus mengusulkannya terpisah.
  • Pencarian berbasis kata kunci (BM25), bukan makna; cari_teks tidak mengenali sinonim.
  • Alat Git hanya membaca yang sudah di-commit.
  • Urungkan memulihkan berkas yang dihapus dari snapshot journal, bukan dari Tempat Sampah.
  • Riwayat percakapan belum bisa dicari dari panel; cari lewat berkasnya di .nyerat/chats/.
  • Perkiraan token kasar (3 karakter per token).

Harness eksternal

  • Baru pi. Status run (antre, bekerja, log) hanya ada selama aplikasi terbuka.
  • Kartu dikenali dari teksnya, jadi menyunting judul kartu yang sedang dikerjakan memutus statusnya.
  • Pertanyaan dikenali dari tanda ? di akhir jawaban.
  • Catatan [[ ]] di kartu disalin saat Kerjakan dengan pi saja; Balas pi tidak menyalinnya lagi. Paling banyak 10 catatan, 8.000 karakter per catatan dan 24.000 total. Di papan, tautan ke catatan yang tidak ada tampil sama seperti tautan biasa.
  • Tanpa extension izin seperti permission-gate, semua alat pi langsung berjalan.
  • Belum ada worktree per kartu, terminal interaktif, atau tampilan diff hasil harness di Nyerat.

Papan kanban

  • Hanya item daftar tingkat atas yang menjadi kartu.
  • Belum ada arsip atau penyuntingan label lewat antarmuka; tulis #tag di judul kartu.
  • Memindah kartu dengan keyboard hanya lewat menu klik kanan.

Beranda

  • Tenggat dan inbox hanya dibaca dari folder kerja yang sedang dibuka (maksimal 300 berkas Markdown).
  • Mengklik tugas membuka papannya tanpa menyorot kartunya.
  • Berkas terbaru dicatat Nyerat sendiri, belum lewat daftar berkas terbaru GNOME, jadi tidak muncul di aplikasi lain.

Jurnal harian

  • Satu folder jurnal tetap (jurnal/ di folder kerja) dengan template tetap; belum bisa diatur di Preferensi.
  • Aktivitas hanya dicatat selama Nyerat terbuka dan hanya untuk folder kerja yang sedang dibuka. Kartu yang dipindah dengan menyunting teks papan, atau papan yang diubah di luar Nyerat, tidak tercatat (commit-nya tetap muncul).
  • Aktivitas digabung saat jurnal dibuka dengan Ctrl+Alt+J atau dari Beranda, bukan selagi jurnal terbuka. Membuka berkas jurnal dari pohon berkas tidak menggabungkannya.
  • Commit dikenali dari hash pendeknya: commit yang di-amend atau di-rebase bisa muncul dua kali. Commit di cabang lain tidak ikut.
  • Urungkan perubahan agent ikut tercatat sebagai perubahan agent.

Editor dan ekspor

  • GIF animasi hanya menampilkan frame pertama; gambar yang diubah di disk dimuat ulang setelah aplikasi dibuka lagi.
  • Teks sel tabel yang panjang dipotong dengan “…”, dan isi sel hanya satu baris.
  • Belum ada tampilan berdampingan atau pengurutan tab dengan seret.
  • Tautan [[ ]]: belum ada panel tautan balik (backlink) atau grafik; mengganti nama atau memindah berkas tidak memperbarui tautan yang menunjuknya; sematan ![[ ]] dan rujukan blok ^id belum didukung; saran [[ hanya nama berkas, belum heading.
  • Ekspor HTML tidak menyematkan gambar lokal dan belum menyertakan warna blok kode.

Integrasi GNOME

  • Antarmuka baru tersedia dalam bahasa Indonesia; infrastruktur terjemahan sudah ada, tetapi belum ada bahasa lain.
  • Belum diuji di sesi Wayland; tes berjalan di X11.
  • Pemasangan lewat Meson dan build Flatpak belum diuji. Di Flatpak, git dan pi harus tersedia di dalam sandbox.
  • Warna aksen sistem dan dialog pintasan Adw.ShortcutsDialog hanya dipakai di libadwaita 1.6/1.8 ke atas; di versi lebih lama dipakai warna Adwaita bawaan dan daftar pintasan biasa.
  • Panel yang melayang di jendela sempit tidak tertutup saat editor diklik; tutup lewat tombolnya.
