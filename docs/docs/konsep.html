Memulai

Konsep dasar

Empat prinsip yang menjelaskan cara Nyerat bekerja. Bila sebuah perilaku terasa mengejutkan, biasanya jawabannya ada di sini.

Folder kerja adalah konteksnya

Nyerat bekerja di satu folder yang Anda buka: catatan, dokumen, riset, rencana, dan papan tugas. Agent menerima peta seluruh berkas Markdown di folder itu, isi dokumen yang terbuka (termasuk yang belum disimpan), teks yang dipilih, dan posisi kursor. Selebihnya ia telusuri sendiri dengan alat baca.

Tanpa folder yang dibuka, agent hanya melihat dokumen aktif dan tidak bisa mengusulkan berkas baru atau perubahan pada berkas lain.

Semua tetap Markdown biasa

Dokumen, papan kanban, dan riwayat percakapan disimpan sebagai berkas Markdown. Tidak ada basis data, format tertutup, atau akun. Semuanya bisa dibaca editor lain, di-diff, dan di-commit ke Git.

  • Papan kanban adalah berkas Markdown dengan kanban: true di frontmatter.
  • Percakapan dengan agent tersimpan di .nyerat/chats/ di folder kerja.
  • API key memakai milik Anda sendiri dan disimpan di keyring sistem.

Agent membaca bebas, menulis lewat usulan

Alat baca (menelusuri, membaca berkas, membaca riwayat Git) langsung dijalankan. Alat tulis tidak menulis apa pun: setiap tindakan menjadi usulan yang tampil di jendela tinjau. Berkas baru tersentuh setelah Anda menekan Terapkan.

Batas tulis

Usulan hanya boleh menyentuh berkas Markdown di folder kerja. Nama di luar folder, bertitik, atau berisi .. ditolak. Berkas yang berubah sejak diusulkan tidak ditimpa.

Transparan soal konteks dan biaya

Tiap jawaban memperlihatkan konteks yang dikirim, penelusuran yang dilakukan, dan pemakaian token. Saklar konteks menentukan dokumen mana yang boleh dikirim ke penyedia model. Jendela Log agent menampilkan setiap putaran model dan panggilan alat secara langsung.
