Pengaturan

Pengaturan disimpan otomatis saat Anda mengubahnya dari menu atau panel. Tidak ada akun dan tidak ada sinkronisasi ke server.

Lokasi berkas

BerkasIsi
GSettings (id.eka.Nyerat)Pengaturan aplikasi, disimpan di dconf
Keyring sistemAPI key DeepSeek
~/.config/nyerat/deepseek.keyAPI key bila keyring tidak tersedia (mode 0600)
<folder kerja>/.nyerat/chats/Riwayat percakapan, rencana, dan journal tindakan

Isi pengaturan

Buka dialog Preferensi (Ctrl+,) untuk tema warna, mode fokus dan typewriter, simpan otomatis, serta model asisten. Perintah apa pun juga bisa dicari lewat Palet Perintah (Ctrl+Shift+P).

  • Tema warna (ikuti sistem, terang, atau gelap), sidebar dan tab sidebar yang terakhir dipilih
  • Folder terakhir dan tab berfile yang terbuka (urutan, tab aktif, posisi kursor)
  • Mode fokus, typewriter, dan auto save; ukuran jendela
  • Panel Asisten: terbuka atau tidak, model, dan mode berpikir
  • projects: pemetaan nama proyek → folder untuk harness eksternal

API key tidak pernah ditulis ke pengaturan.

API key

Nyerat mencari API key dari variabel lingkungan DEEPSEEK_API_KEY, lalu dari keyring, lalu dari berkas cadangan. Isi atau ganti key dari ikon roda gigi di panel Asisten.
