Memulai

Mulai cepat

Nyerat adalah personal workbench AI agent untuk desktop Linux. Anda dan agent bekerja di folder yang sama: agent menelusuri catatan, rencana, dan papan tugas Anda, lalu mengusulkan perubahan yang baru ditulis setelah Anda menyetujui selisihnya.

Pasang

Nyerat dijalankan oleh GJS, bukan Node.js. Node.js hanya dibutuhkan sekali untuk membangun kodenya. Di Ubuntu atau Debian:

# wajib: GJS, GTK 4, dan GtkSourceView 5
sudo apt install gjs gir1.2-gtk-4.0 gir1.2-gtksource-5

# agent AI: libsoup 3 dan (opsional) keyring untuk API key
sudo apt install gir1.2-soup-3.0 gir1.2-secret-1

# opsional: diagram Mermaid dan DBML
sudo apt install gir1.2-webkit-6.0

Tanpa libsoup hanya agent yang tidak berfungsi. Tanpa libsecret, API key disimpan di berkas berizin 0600. Tanpa WebKitGTK, diagram menampilkan pesan galat dan bagian lain tetap berjalan.

Ambil kode dan jalankan

Perlu Node.js 20.19+ atau 22.12+ untuk build.

git clone https://github.com/EkaPutCom/nyerat.git
cd nyerat
npm install
npm start

Setelah di-build, aplikasi bisa dibuka langsung dengan sebuah berkas atau folder:

gjs -m dist/nyerat.js ~/catatan          # buka folder kerja
gjs -m dist/nyerat.js rencana.md         # buka satu berkas

Sambungkan agent

  1. Buka panel Asisten dengan Ctrl+Shift+A atau tombol gelembung di header bar.
  2. Klik ikon roda gigi, lalu isi API key DeepSeek. Key disimpan di keyring sistem, tidak di pengaturan aplikasi. Variabel lingkungan DEEPSEEK_API_KEY juga dikenali.
  3. Buka sebuah folder kerja (Ctrl+Shift+O) supaya agent bisa menelusuri berkas lain dan mengusulkan perubahan.

Coba alur pertama

Misalkan folder kerja Anda berisi rencana peluncuran, catatan rapat, dan papan tugas. Ketik di panel Asisten:

  1. Tanya. “Adakah keputusan rapat yang belum masuk ke rencana peluncuran?” Agent mencari sendiri dan menjawab dengan kutipan berkas dan nomor baris.
  2. Minta bertindak. “Perbarui tanggal rilisnya dan pindahkan kartu materi rilis ke Dikerjakan.” Agent mengusulkan perubahan teks dan perpindahan kartu.
  3. Tinjau. Jendela tinjau menampilkan selisihnya seperti diff Git. Tekan Terapkan atau Tolak.
