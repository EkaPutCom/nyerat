Editor Markdown

Tidak ada panel pratinjau terpisah. Teks langsung tampil terformat, dan sintaks Markdown muncul hanya di baris tempat kursor berada.

Format langsung

  • Heading, tebal, miring, coret (~~), stabilo (==), kode inline, tautan, dan gambar langsung terformat.
  • Sintaks seperti **, ==, atau []() muncul lagi saat kursor masuk ke barisnya.
  • Kutipan bersarang >> makin menjorok sampai tiga tingkat.
  • Tautan dibuka dengan Ctrl+klik; path relatif dihitung dari folder berkas.

Daftar dan tugas

  • Enter melanjutkan daftar, daftar bernomor, daftar tugas, dan kutipan; Enter di item kosong mengakhirinya.
  • Tab / Shift+Tab mengatur indentasi item.
  • Kotak - [ ] bisa dicentang dengan klik.

Tabel sebagai grid

Tabel digambar dengan garis sel, header tebal, dan rata kiri/tengah/kanan. Saat kursor masuk, teks mentahnya muncul untuk disunting; klik sebuah sel untuk langsung menyunting sel itu.

  • Tab / Shift+Tab pindah antar sel; di sel terakhir, Tab menambah baris.
  • Enter pindah ke baris berikutnya; di baris kosong terakhir, keluar dari tabel.
  • Menu ☰ → Edit Tabel menambah/menghapus baris dan kolom, mengatur rata, dan merapikan kolom (Ctrl+Shift+T).
  • Tabel yang lebih lebar dari kolom teks dipersempit, dan teks terpotong diberi “…” dengan isi lengkap sebagai tooltip.

Blok kode berwarna

Isi blok kode diwarnai sesuai bahasanya (```js, ```python, ```rust, dan ratusan bahasa lain dari GtkSourceView), dengan skema warna yang mengikuti mode terang atau gelap.

Gambar dan zoom

Gambar ![alt](url) tampil di bawah barisnya, dari berkas lokal maupun internet. Klik ganda (atau menu ☰ → Perbesar Gambar) membuka penampil: roda mouse memperbesar di titik penunjuk, +/−, 0 untuk 100%, F untuk pas layar, geser dengan drag, Esc menutup.

Simpan dan ekspor

  • Auto save (aktif bawaan): dokumen yang sudah punya berkas disimpan 1 detik setelah berhenti mengetik, di latar sehingga tidak menahan ketikan.
  • Peringatan muncul sebelum menutup bila ada perubahan yang belum tersimpan.
  • Ekspor HTML (Ctrl+Shift+E): satu berkas HTML mandiri dengan CSS. Diagram di hasil ekspor memuat Mermaid dari CDN.
