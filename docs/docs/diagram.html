Diagram Mermaid dan DBML

Blok ```mermaid dan ```dbml digambar sebagai diagram langsung di dokumen, dirender lokal tanpa internet.

Mermaid

```mermaid
flowchart LR
  Rencana --> Dikerjakan --> Review --> Selesai
```
  • Flowchart, sequence, class, state, ER, gantt, pie, dan jenis lain yang didukung Mermaid.
  • Saat kursor di luar blok, hanya diagram yang terlihat. Saat kursor masuk, kodenya muncul dan diagram menjadi pratinjau di bawahnya yang ikut berubah selagi mengetik.
  • Galat sintaks tampil di bawah blok; kodenya tidak disembunyikan.
  • Klik ganda memperbesar diagram. Warnanya mengikuti mode terang atau gelap.

DBML (dbdiagram.io)

```dbml
Table pengguna {
  id int [pk]
  email varchar [unique]
}
Table catatan {
  id int [pk]
  pengguna_id int [ref: > pengguna.id]
}
```

Skema DBML digambar sebagai diagram ER dengan perilaku yang sama seperti Mermaid. Yang didukung: Table (alias, pk, unique, note, ref: di dalam kolom, indexes), Ref satu baris maupun blok dengan relasi > < - <>. Enum, TableGroup, Project, dan Note dilewati. Kolom di sisi “banyak” relasi otomatis bertanda FK.

Kebutuhan

Diagram membutuhkan WebKitGTK 6.0 (gir1.2-webkit-6.0). Tanpanya, blok diagram menampilkan pesan galat dan bagian lain aplikasi tetap berjalan.
